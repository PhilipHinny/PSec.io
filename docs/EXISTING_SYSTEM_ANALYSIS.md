## Risk list, prioritized

1. **Critical — committed database credential:** `PSecAI-Server/config.py:8` embeds a credential-bearing URI fallback. Assume compromise, rotate and audit use, then remove in an authorized code/provider session. Do not put the value in tickets or logs.
2. **Critical — unauthorized reads/writes:** No Flask token verification; user-controlled IDs can select another user's Mongo data (`routes/sidebar.py:10-20`, `routes/deleteDocument.py:9-20`). `routes/Downloads.py:17` selects only by filename. Do not expose legacy endpoints as v3 routes.
3. **High — untrusted customer content and fabricated output:** raw document/prompt text and model response are logged (`database.py:24-26`, `services/ai_service.py:102-105,119`); free-form generation has no evidence or numeric checks (`services/ai_service.py:96-135`). Existing logs may need separate retention review.
4. **High — payment integrity:** browser-selected amount reaches Paystack (`src/pages/BillingPage.jsx:92-106`, `routes/paystackpayment.py:31-51`); callback only shows an alert (`src/pages/BillingPage.jsx:138-140`). No verified webhook or server-owned entitlement. Do not use this for paid access.
5. **High — export and deletion trust:** client export bypasses human approval and watermark; server download has no ownership check; delete removes only one Mongo row (`src/pages/ActivityPage.jsx:100-108`, `routes/Downloads.py:17-35`, `routes/deleteDocument.py:19-24`).
6. **High — data provenance unknown:** ten PDFs are tracked; remote stores and deployed state unverified. Treat as possibly real data. Inventory only metadata with owner approval before migration; do not publish or delete artifacts blindly.
7. **Medium — runtime and operational gaps:** `/get_reports` arity error; separate FastAPI app is not mounted; server Python 3.11 conflicts with v3 3.12; no tests or deploy manifest; wildcard credentialed CORS (`routes/get_reports_routes.py:14`, `services/ai_service.py:17`, `runtime.txt:1`, `app.py:29`).
